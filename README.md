# EdgeEver 人际关系管理插件

以笔记为中心管理你的人际网络。每位联系人是一篇带有「人际」标签的笔记，插件在此基础上提供：

- **新建联系人**：结构化表单生成联系人卡片，自动归入「人际关系」笔记本并打标签。
- **编辑联系人**：在面板中点击「编辑」，通过表单修改字段并自动写回笔记（旧版「电话」「认识于」字段会自动迁移为新字段），同时在互动记录追加更新日志。
- **人际关系面板**：全屏仪表盘，集中浏览、搜索所有联系人，点击直接打开对应笔记。
- **统计联系人数量**：快速查看当前人脉规模。
- **可配置**：联系人标签、笔记本名称、自定义扩展字段均可在插件设置页修改（宿主渲染设置，符合 Plugin API v2）。

## 联系人字段与校验

| 字段 | 输入方式 / 校验规则 |
| --- | --- |
| 姓名 | 必填（作为笔记标题） |
| 性别 | 下拉：男 / 女 / 其他 / 保密 |
| 婚况 | 下拉：未婚 / 已婚 / 离异 / 丧偶 / 保密 |
| 身高(cm) | 仅数字和小数点，0–300 |
| 体重(kg) | 仅数字和小数点，0–500 |
| 鞋子尺码 | 仅数字和小数点，0–100（支持 42.5 等半码） |
| 手机号 | **只能输入纯数字**（输入时自动过滤非数字字符），5–20 位 |
| 曾用手机号 | 同手机号，纯数字 |
| 身份证号 | 18 位，前 17 位数字、末位可为 X（自动转大写） |
| 邮箱 | 邮箱格式校验 |
| 生日 | 日期选择器 |
| 关系 / 公司·单位 / 认识场合 | 自由文本 |
| 自定义扩展字段 | 设置中用逗号配置（默认：微信、QQ、住址），最多 20 个 |

校验失败时字段下方会显示红色错误提示，并自动聚焦到第一个出错项。

## 安装

在 EdgeEver 的 **插件市场**（独立页面或 设置 → 插件）中粘贴本仓库地址安装：

```text
https://github.com/zwjdujin/edgeever-rjgx
```

要求：EdgeEver 默认分支（main）含根目录 `manifest.json`，并发布同名版本的 GitHub Release（本仓库已满足）。

> 若提示 `Repository manifest request failed with HTTP 403`，是 GitHub 匿名 API 对当前出口 IP 限流（60 次/小时）所致，与仓库本身无关。等几分钟重试，或更换网络即可。

## 仓库结构

```text
manifest.json   # EdgeEver 扩展清单（type: plugin, entry: ./main.js）
main.js         # 插件单文件包（ESM，无相对导入）
.zcode-plugin/  # 同仓库的 ZCode 技能定义（与 EdgeEver 插件互不影响）
skills/         # ZCode 技能文件
```

## 使用建议

- 联系人笔记就是普通笔记，可以直接在编辑器里补充信息、写互动记录，面板会实时反映。
- 卸载插件不影响已有笔记；标签和笔记本都保留。
